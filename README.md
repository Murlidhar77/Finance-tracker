# FinTrack Pro 💰

**A personal finance dashboard built with HTML, CSS and JavaScript.**

FinTrack Pro is a personal finance tracker that helps users manage their income and expenses through a clean, interactive dashboard. I built this project to improve my frontend development skills and get more practical experience working with JavaScript, DOM manipulation, data handling and browser storage.

The main goal was to build something that feels like a real application rather than just another static webpage.

## ✨ Features

- **Financial Overview:** Dashboard cards displaying current balance, total income, total expenses and savings rate.
- **Transaction Management:** Add income and expense transactions with descriptions, amounts, dates and categories.
- **Transaction Filtering:** Filter recent transactions by All, Income and Expenses.
- **Transaction Sorting:** Organize transactions by date.
- **Cash Flow Visualization:** Visualize income and expenses over time using Chart.js.
- **Multiple Currencies:** Currency selection for INR, USD, EUR and JPY.
- **Dark & Light Mode:** Switch between themes for a different viewing experience.
- **Custom Profile:** Update your profile name and profile picture.
- **Data Persistence:** Use browser localStorage to retain application data and preferences.
- **Category Icons:** Display visual indicators for different transaction categories.
- **Reset Data:** Reset stored application data when needed.

## 🚀 Getting Started

You can run this project locally in a few steps.

1. Clone the repository:

```bash
git clone YOUR_REPOSITORY_URL
```

2. Open the project folder.

3. Run `index.html` in your browser or use the Live Server extension in VS Code.

No build tools or package installation are required for the current vanilla JavaScript version.
