# 💰 FinTrack Pro — Personal Finance Dashboard

**Track. Plan. Grow.**

FinTrack Pro is a personal finance management dashboard I'm building to make tracking income, managing expenses, and understanding personal finances easier.

The idea behind this project is simple: having a clear picture of where your money comes from, where it goes, and how much you save.

This project is currently a work in progress. I'm actively developing it, improving existing functionality, and adding new features as I learn and experiment with JavaScript and frontend development.

## 🚧 Project Status

**Currently under development — Not completed yet.**

The dashboard already has several working features, but there is still plenty to build. I'm continuously working on improving the experience, fixing bugs, and introducing new functionality.

## ✨ Current Features

Here are some of the features implemented so far:

- **Dashboard Overview** – View your current balance, total income, total expenses, and savings rate.
- **Income Tracking** – Add and manage income transactions.
- **Expense Tracking** – Record daily expenses and categorize your spending.
- **Dynamic Transaction Table** – Transactions are displayed dynamically with dates, descriptions, categories, types, and amounts.
- **Category Icons** – Different transaction categories have their own icons and colors.
- **Profile Customization** – Set a personal name and profile image.
- **Local Storage** – Profile information and transaction records persist in the browser using `localStorage`.
- **Cash Flow Section** – A chart area designed to visualize earnings and spending over time.
- **Theme Controls** – Light and dark theme controls are included in the interface.
- **Currency Selector** – A currency selection interface is available.

## 🛠️ Tech Stack

This project is being built using:

- **HTML5** – Structuring the dashboard.
- **CSS3** – Styling, layouts, custom properties, and visual design.
- **JavaScript (Vanilla JS)** – DOM manipulation, event handling, dynamic rendering, and application logic.
- **LocalStorage** – Saving user and transaction data locally.
- **Chart.js** – Chart visualization.
- **Remix Icon** – Transaction category icons.
- **Lucide Icons** – Interface icons.

## 📸 About the Project

FinTrack Pro is designed with a modern dashboard layout, featuring a sidebar, navigation area, financial summary cards, a cash flow section, and a transaction management area.

The goal is to make financial information easy to understand without overwhelming the user with unnecessary complexity.

## 🚀 Getting Started

Want to explore the project locally?

1. Clone this repository:

   ```bash
   git clone YOUR_REPOSITORY_URL
   ```

2. Open the project folder:

   ```bash
   cd FinTrack-Pro
   ```

3. Open `index.html` in your browser.

No additional installation is currently required.
